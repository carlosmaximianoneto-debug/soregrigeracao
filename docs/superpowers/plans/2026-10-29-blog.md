# Blog Só Refrigeração Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. Independent content and tracking tasks are delegated; root integrates and verifies.

**Goal:** Publish 20 useful buying guides that attract refrigeristas from search and lead to the existing WhatsApp entry group.
**Architecture:** Server-rendered editorial routes `/blog/` and `/blog/<slug>/`, versioned structured content, existing brand/styles, sitemap integration and shared invitation contract. Isolated anonymous aggregate blog click counters preserve existing product metrics. No new CMS dependency.
**Tech Stack:** Existing Node22 VPS container, HTML/CSS, Supabase Edge/Postgres isolated blog counters.
**Spec:** User asked to measure keywords, create20 articles, expose only a footer shortcut on homepage, focus on joining WhatsApp, continue until publication. This is explicit execution authorization, no intermediate approval required.

## Constraints
- No bot/app restart or DB product mutation. Container resource/security limits unchanged.
- Blog can render without catalogue availability. No copying product descriptions into thin posts.
- Technical claims cite verified primary sources; no fabricated tests/authors/credentials, search volumes or ranking guarantees.
- Homepage blog link only in footer, never hero/header/carousel. Existing three WhatsApp invitations preserved.
- Same invitation from build/serverOptions throughout blog; future publisher changes flow automatically.
- Blog tracking contains only approved article slug/event/placement, no user IDs, IP storage, cookies or search terms. RLS admin-only reads, service-only RPC.
- Keyword volume unavailable in Semrush/API quota and Ahrefs/plan; retrieve actual Search Console data and document unavailable total-market volumes separately.
